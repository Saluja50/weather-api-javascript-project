# 🌤️ Weather API JavaScript Project

This is a simple weather application built with JavaScript that fetches real-time weather data using a public weather API like OpenWeatherMap. Users can search for any city to view the current weather conditions including temperature, humidity, wind speed, and weather description.

## 🚀 Features

- Search weather by city name
- Displays temperature, weather condition
- Uses Fetch API to interact with weather data

## 🛠️ Technologies Used

- HTML5 / CSS3
- JavaScript
- [OpenWeatherMap API](https://openweathermap.org/api)
